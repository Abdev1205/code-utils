# Kubernetes Basics

An example track, so a fresh clone has something to look at. Three modules, no lessons
written yet — press **Teach me this** on any topic and one gets written.

Everything here is generic. Copy the folder, change `track.json`, and write your own
modules.

## Learning order

| When | Study | Because |
|---|---|---|
| First | `01` what a cluster is | Nothing else makes sense without it |
| Then | `02` running something | The objects you touch every day |
| Then | `03` when it breaks | Reading a failure instead of guessing |

## Modules

- [ ] `01-what-a-cluster-is.md` Nodes, the control plane, the desired-state loop
- [ ] `02-running-something.md` Pods, Deployments, Services, config
- [ ] `03-when-it-breaks.md` Reading events, logs and the usual failure modes
